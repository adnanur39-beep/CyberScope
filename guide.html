CYBER HYGIENE

Build safer digital habits.

Practical steps that reduce common security risks for students, teams and everyday internet users.

01

Use strong, unique passwords

Create a different password for each important account. Use a reputable password manager and enable multi-factor authentication whenever possible.

02

Keep software updated

Install operating system, browser and application updates. Security patches often fix vulnerabilities that attackers may otherwise exploit.

03

Recognize phishing attempts

Be careful with unexpected links, attachments, urgent payment requests and messages asking for credentials. Verify the sender through a separate trusted channel.

04

Protect personal information

Share only what is necessary. Review privacy settings and avoid posting sensitive information publicly.

05

Use networks carefully

Avoid sensitive activity on untrusted public Wi-Fi. Use HTTPS websites and a trusted network or VPN when appropriate.

06

Back up important files

Maintain regular backups and keep at least one backup separate from your everyday device to reduce the impact of device failure or ransomware.

Responsible use

Use CyberScope only for lawful learning and analysis of public IP information. Do not use technical information to harass, target or attempt unauthorized access to any person, device or network.
